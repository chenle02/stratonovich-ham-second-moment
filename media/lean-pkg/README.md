# lean-pkg logo

`lean-pkg-logo-256.png` is the logo of lean-pkg, the author's tool for
registering and checking Lean packages. It is shown next to the lean-pkg
paragraph of Appendix F ("What Lean checks"). It is copied unchanged from the
lean-pkg repository (`docs/assets/logo-256.png`); the source commit, licence
and SHA-256 hash are in `PROVENANCE.json`.
