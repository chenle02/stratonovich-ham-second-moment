# A guitar in a sandstorm

A guitar left outdoors in a sandstorm provides a memorable starting point for
stochastic wave equations. Random impacts on a string suggest random forcing;
the mathematical question is how those impulses combine into a vibrating wave.
Walsh used this example in his 1986 lecture notes, based on the 1984 Saint-Flour
course. In the worked example on page 282 he idealizes the string as infinite
to avoid boundary conditions.
