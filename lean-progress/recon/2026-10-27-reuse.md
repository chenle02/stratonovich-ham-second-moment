## Proposed faithful first-wave signatures

These are **unelaborated specifications**, not compiled declarations or proofs.
The code below is documentary; no Lean module or package was created.

Use the same actual type as the compatible Physlib theorem:

```lean
abbrev PairingOn (n : ℕ) :=
  {f : Fin n → Fin n // Function.Involutive f ∧ ∀ i, f i ≠ i}
```

Each such function has unordered two-element orbits `{i,f i}`. Every vertex
belongs to one orbit and every unordered pair is counted once; pairs entirely
inside either chain remain allowed. The manuscript interface should explicitly
identify these orbits with its pair partitions. No bipartite restriction may
be added. If a weighted sum is introduced later, use one representative per
pair, for example `i < f i`, and prove the representative/relabeling fidelity
before applying it to diagram weights.

Initial targets:

```lean
card_pairings_mul_factorials (k : ℕ) :
  Fintype.card (PairingOn (2*k)) * (2^k * Nat.factorial k)
    = Nat.factorial (2*k)

card_pairings_factorial_quotient (k : ℕ) :
  Fintype.card (PairingOn (2*k))
    = Nat.factorial (2*k) / (2^k * Nat.factorial k)

pairing_count_bounds (k : ℕ) :
  Nat.factorial k ≤ Fintype.card (PairingOn (2*k)) ∧
  Fintype.card (PairingOn (2*k)) ≤ 2^k * Nat.factorial k
```

The multiplication statement is a useful primary consumer because it exposes
all denominator obligations. Its quotient corollary uses positivity of
`2^k*k!`. The `(2*k-1)‼` upstream expression uses natural subtraction;
at `k=0` it is `0‼=1`, so the empty pairing case is included.

For the chain splits, reuse the actual antidiagonal object and membership
`m+n=2*k`, not a bare numeral count disconnected from the summation. For the
source partition, a finite-set consumer is preferable to only a scalar toy:

```lean
source_partition_half_count
  (k : ℕ) (Q0 Q1 Q2 : Finset (Fin (2*k)))
  (h01 : Disjoint Q0 Q1) (h02 : Disjoint Q0 Q2)
  (h12 : Disjoint Q1 Q2)
  (hcover : Q0 ∪ Q1 ∪ Q2 = Finset.univ)
  (hequal : Q0.card = Q1.card) (heven : Even Q2.card) :
  Q0.card + Q2.card / 2 = k
```

Derive `q0+q1+q2=2*k` from the actual disjoint cover using Mathlib, then use
natural arithmetic. Chen's theorem supplies the existence and analytic role
of the partition externally; this finite consumer does not prove that theorem.

The real-parameter target should preserve every source inequality and derive
positive denominators before division:

```lean
exponent_chain (alpha alpha0 : ℝ)
  (ha : 0 < alpha) (h0 : 0 < alpha0) (h1 : alpha0 < 1)
  (hs : alpha + alpha0 < 2) :
  let beta := 4 - alpha - alpha0
  let kappa := beta / (3-alpha)
  let rho := beta / (3-alpha-alpha0)
  2 < beta ∧ 1 < kappa ∧ kappa < rho ∧ rho < 2
```

A useful exact difference identity is `rho-kappa =
beta*alpha0/((3-alpha-alpha0)*(3-alpha))`, proved from the same positive
parameter domain. These signatures have not been checked by the elaborator.
No part of the signature should assume the desired exponent comparison.
