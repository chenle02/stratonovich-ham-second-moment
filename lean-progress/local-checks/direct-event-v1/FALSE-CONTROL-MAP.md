# Semantic controls

WrongNoiseExponent uses alpha1,a1/2 in the actual original parameter class.
It changes the equation's sqrt(delta) amplitude to delta and rejects the
resulting false EXACT rational exponent identity. It is an exponent test,
not a numerical evaluation of a real-power function.

WrongGaugeSquare evaluates the actual gauge conjugation at omega1/100,
inside eta<=1/80, and falsely omits the negative square in the bottom-left
entry. WrongInverse uses the same small omega and falsely uses the same
sign in both gauge factors. Both resolve the full matrix definitions.

All three current controls resolve imports/names and then fail on False.
The initial controls at omega1 checked unrestricted algebra only and are
preserved as history, not counted as three additional scoped controls.
