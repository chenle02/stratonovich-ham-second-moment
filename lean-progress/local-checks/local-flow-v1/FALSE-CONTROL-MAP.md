# Semantic controls

WrongMaskEndpoint instantiates actual noiseOrder at excluded alpha0; strict
b<1/2 becomes false. It does not refute an admissible positive-alpha model.
WrongWhiteWitness instantiates actual sourceSigma at alpha1; its strict
source condition becomes equality and fails. This is not an all-method no-go.
WrongSchurCancellation uses abstract positive factors A2,B3 and deletes the
remaining A after cancellation. It hard-codes reduced factors, not physical
frequencies/definitions. Exact Schur applications have a separate type audit.
All three imports/referenced names resolve, then fail on False. Warning-only
v1 is not a mathematical failure. No control/source proposition weakened.
