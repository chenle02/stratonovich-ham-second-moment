# Exact source history is not strict blindness

The frozen scientific draft itself contains historical review prose, including
mainTeX98–99,223–225 and later myCmts blocks (4413,4562,4804,5375,6638,7021,
7247,7657 in scientific887). These annotations were retained when exact source
bodies/context were supplied. Excluding separate prior REPORT files and
identity-verdict metadata is not the same as removing every review-history
phrase inside the source. The blind-prior-review tool flag suppresses selected
workflow artifacts; it does not redact those frozen source annotations.

Interpret raw prior_reviews_supplied=false fields as the declared absence of
separate prior review reports, NOT as a certificate of strict textual blindness.
Raw launch/source receipts remain immutable. New receipts explicitly separate
these notions. Mathematical arguments must stand on their source bodies and
hypotheses, never on the historical votes. All adoptions are scoped textual
reviews; none has been credited as the required fresh independent cold read.

A future cold packet must handle review-history exposure explicitly while
preserving every mathematical statement/proof and auditable source binding.
No scientific source is redacted or changed during these live frozen audits.
This disclosure does not relax any confidence, source-image or cold gate.
